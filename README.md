# Iron Nest Wiki

Fan-made first version of an IRON NEST: Heavy Turret Simulator guide site.

## Run Locally

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:4173/
```

## Check

```bash
npm run check
```

The check validates the first route set, title and description length, unique slugs, and article section depth.
